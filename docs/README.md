# Learning Python: Course Docs

Materials for learning Python in the Classroom Python editor.

> **Both run modes:** everything here works in *Tablet mode* (Skulpt) and *Pi mode* (CPython).
> Skulpt has no f-strings and a small standard library, so examples use `+`, `str()`,
> commas in `print`, and `%` formatting instead. Sections marked **(Pi mode)** need full Python.

## How to use a lesson

1. Read the short explanation.
2. Type (don't paste) each example into the editor and press **Run**.
3. Change something and predict what happens before running.
4. Do the **Try it** exercises, then the matching lab.
