# Labs

Seven short labs, one per lesson. Each lab has a **starter** (fill in the `TODO`s) and a **solution**.

| Lab | Topic | Lesson | Starter | Solution |
|---|---|---|---|---|
| 1 | Greeter | 01-02 | [starter](starters/lab1_greeter.py) | [solution](solutions/lab1_greeter.py) |
| 2 | Tip calculator | 03 | [starter](starters/lab2_tip.py) | [solution](solutions/lab2_tip.py) |
| 3 | Number guesser | 04-05 | [starter](starters/lab3_guesser.py) | [solution](solutions/lab3_guesser.py) |
| 4 | Times tables | 05 | [starter](starters/lab4_tables.py) | [solution](solutions/lab4_tables.py) |
| 5 | Shopping list | 06 | [starter](starters/lab5_shopping.py) | [solution](solutions/lab5_shopping.py) |
| 6 | Temperature converter | 07 | [starter](starters/lab6_temperature.py) | [solution](solutions/lab6_temperature.py) |
| 7 | Quiz | 08 | [starter](starters/lab7_quiz.py) | [solution](solutions/lab7_quiz.py) |

All labs run in both Tablet mode and Pi mode (no f-strings).
Stretch goals are at the bottom of each starter file. Try before peeking at the solution.
