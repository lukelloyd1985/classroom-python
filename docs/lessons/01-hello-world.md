# 01 Hello World

## Printing
`print()` shows text on the screen. Text goes in quotes.

```python
print("Hello, world!")
print('Single quotes work too')
print("Two", "things", "on one line")
```

## Comments
Anything after `#` is ignored by Python. Use it to explain your code.

```python
# This line does nothing
print("This line runs")  # so does this, but the comment is ignored
```

## Errors are normal
Python tells you the line number and what went wrong.

```python
print("Missing the closing bracket"
```
Fix it by adding `)`. Common first errors: missing quote, missing bracket, wrong capital letters (`Print` vs `print`).
