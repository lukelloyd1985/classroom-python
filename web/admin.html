Classroom Python - teacher controls

Teacher PIN:
The PIN is printed when the server starts and saved in admin_pin.txt in the data folder on the Pi.
Where do students' programs run?
Tablets pick up the change within about 5 seconds. A program that is already running finishes where it started.
Every tablet wipes its saved code within about 5 seconds, or the next time it connects if it is off now. Students can also clear their own with the New button.
